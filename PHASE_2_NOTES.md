# Phase 2 — Real CRM UI + visual polish

## Final scope

Phase 2 intentionally uses only three product views so the marketing website stays focused and premium rather than becoming product documentation.

- Dashboard — used in the hero as the main CRM overview.
- Revenue — used in the product showcase.
- Analytics — used in the product showcase.

UTM Leads, Admissions, Goals & Targets, Settings, Help & Support and Login screenshots are not used in this phase. Their capabilities can still be explained through website copy/module cards.

## Data treatment

- Student Mentor tenant branding is not shown.
- Testing/customer-specific values are not shown.
- The three product screenshots use neutral empty states instead of invented sample metrics.
- The website presents the actual CRM UI structure without pretending demo values are real.
